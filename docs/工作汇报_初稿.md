# 基于 DINOv3 的无线信号时频图识别：流程搭建与初步实验

**阶段性工作汇报**　汇报人：____　日期：2026-10-11

## 一、工作背景与目标

本次工作的目标有两个：一是独立跑通"信号仿真生成 → 时频分析 → 事件检测与切图 → 数据集构建 → 深度学习分类 → 评测"的完整工作流程，并保证每一步可复现、结果可核查；二是学习并实践 DINOv3 在非自然图像领域（无线电时频图）的应用方法，即利用冻结的预训练视觉特征配合轻量分类头完成 CW / 2FSK / LFM 三分类。本阶段不追求提出新算法，重点是验证该技术路线的可行性并摸清其边界。

## 二、工作流程

按数据流向分为四个阶段，每阶段有独立产物与脚本（见图 1）。

**阶段一：数据生成**　（工具：GNU Radio 仿真）

用 GNU Radio 搭建三类信号的仿真链路，输出复数基带 IQ 信号。信号的固有特性为：CW / 2FSK / LFM 的时频形态分别是单频线、双频交替与调频斜线；信号经突发包络门控，并非持续存在——2 s 记录内共 6 段突发且长短位置不一，段间为纯噪声；信道环节引入了 5 kHz 频偏与可控信噪比的加性高斯白噪声（AWGN）。**作用**：获得类别标签精确、噪声与种子等条件完全可控、可复现的训练数据——这是仿真路线相对实测数据的核心优势，也决定了后续处理的设计动机。产物：原始 IQ 文件。

**阶段二：时频处理与数据集构建**　（工具：numpy / Pillow）

对 IQ 依次完成：STFT 时频转换（把一维时序变成二维时频图，使信号可借用视觉模型处理）；突发检测（先估计背景噪声再作门限判决，因为信号是间歇出现的，必须定位有效段）；中心对齐与切窗（先消除 5 kHz 频偏等与类别无关的频率平移，再从每段突发截取等长窗口，把长短不一的突发统一为定长样本）；灰度成像（把数值矩阵转为尺寸、量纲统一的图片，满足模型输入要求）；最后按 IQ 记录分组划分训练/验证/测试集。**作用**：把原始 IQ 转化为结构统一、无同源泄漏的时频图数据集（共 503 张，训练/验证/测试为 305/108/90）。产物：时频图数据集。

**阶段三：特征迁移训练**　（工具：timm 加载 DINOv3-S/16 冻结骨干 + 轻量分类头）

用 timm 加载 `vit_small_patch16_dinov3.lvd1689m`，冻结全部骨干参数，只训练一个"全连接 → ReLU → Dropout → 全连接"的两层分类头，输入经 Resize、ToTensor 与标准化。**作用**：复用 DINOv3 在大规模自然图像上预训练得到的通用视觉表示，把训练压缩为极低成本的特征分类问题（小样本下 1 轮即收敛）。本阶段只训练分类头、不微调骨干，属于冻结特征的迁移使用。产物：分类头权重。

**阶段四：评测与泛化验证**　（工具：自建批量推理评测脚本 + 新种子留出集）

对全部图片批量推理，按"类别 × 信噪比"统计检出事件数、导出图片数与分类正确数，并生成混淆矩阵；另用一组从未参与训练的噪声种子重新生成留出集，只测不训。**作用**：把"检测失败"与"分类错误"分开定位，明确性能瓶颈在流程的哪一环，并检验对新噪声样本的泛化能力。产物：性能报告。

## 三、实验与结果

**数据规模**：三类信号共 84 条 IQ、503 张时频图；其中噪声实验为 3 类 × 9 档 SNR（−12 ~ 20 dB）× 3 个噪声种子 = 81 条记录、486 个事件。

**检测结果**：−12 ~ 20 dB 全部突发均被检出（10 dB 门限）；仅在 −12 dB 出现偶发突发碎裂（碎片不足 65.5 ms 窗口而被跳过，属检测端损失，每轮约 1~8 个碎片）。

**分类结果（核心发现）**：仅用 20 dB 数据训练分类头时，CW 与 LFM 在全 SNR 范围保持稳定，但 2FSK 随信噪比下降急剧退化——0 dB 为 94%、−3 dB 降至 33%、−6 dB 为 5.6%、−9 与 −12 dB 降为 0%，且错分全部指向 CW（双线结构被噪声淹没后被误认为单频线）。用混合 SNR 数据重训分类头后，各档性能全部恢复。

**结果口径（重要）**：独立留出测试集（5 条记录/类）为 90/90（100%）；全量诊断值为 503 张全部正确、全流程准确率（"检测 → 切窗 → 分类"端到端，分母为结构上应有的全部事件）99.8%（**该口径包含训练与验证样本，不能作为泛化成绩**）；用全新噪声种子与 2FSK 比特种子生成的独立留出集上为 **483/483 张全部正确，全流程准确率 99.4%**，剩余损失全部来自 −12 dB 的检测碎片，而非分类错误。

**初步结论**：瓶颈在分类头未曾见过低信噪比输入，而非 DINOv3 骨干特征或检测器；DINOv3 的冻结特征在时频图上具有良好的迁移性，低信噪比泛化能力可通过混合条件重训分类头获得。骨干可保持冻结。

## 四、遇到的问题与思考

1. **实验独立性**：早期不同 SNR 层复用了同一噪声种子，测试集与训练集的条件相关性偏强；另外随机划分下部分深端条件（如 LFM 的低 SNR）未被测试集覆盖。这也是后来补充"全新种子留出集"的原因。
2. **低信噪比损失的性质**：残余误差集中在检测/切窗环节（突发碎裂不足窗口长度），而不是分类环节。这说明在更强噪声条件下，"是否改进检测与切窗策略"是一个独立于分类模型的问题。
3. **增强设计的任务依赖性**：时频图不能直接照搬自然图像的增强方式——水平翻转会反转调频方向、随机裁剪可能破坏 FSK 的双音结构与 LFM 的扫频结构；哪些扰动是"标签保持变换"取决于任务定义，需要在具体任务下重新设计。
4. **泛化边界**：目前只验证了噪声条件与新种子，尚未验证新波形参数（符号率、频偏、带宽、周期等）以及真实信道与设备差异。
5. **思考**：对同一信号，"核心特征"并不是绝对的，而是由任务决定——环境干扰对识别任务是应当消除的因素，但对某些任务（如射频指纹）反而是关键信息。由此产生一个可继续探索的问题：**如何区分"应当保持不变的任务相关信息"与"应当被扰动消除的环境因素"，并据此设计符合信号物理模型的增强策略**，以提高识别系统对复杂环境的适应能力。
